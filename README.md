A multi-page React + Three.js + Node/Express corporate website revamp built for the Riyadvi Software Technologies Full Stack Developer assignment.

- Interactive 3D experiences

- Service and portfolio exploration

## 3D and Animation

The project uses meaningful 3D and animation technologies rather than adding libraries only for dependency purposes.

### Technologies Used

- Three.js
- React Three Fiber
- Drei
- GSAP
- GSAP ScrollTrigger
- Lenis

### Interactive Experiences

The 3D network ecosystem visual is used across major experiences including:

- Homepage hero
- Service/detail experiences
- Portfolio case-study pages

The 3D scene supports mouse interaction on desktop and automatic movement.

Mobile devices use a reduced rendering strategy with:

- Fewer 3D nodes
- Lower geometry complexity
- Lower device pixel ratio
- Reduced animation intensity
- Reduced connection count
- Disabled desktop mouse interaction

This helps maintain a better balance between visual quality and device performance.
